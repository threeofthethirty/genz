Show the genz quick-reference card.

| Command | What |
|---|---|
| `/genz` | Activate at default level (full) |
| `/genz lite` | Casual, restrained, tiny slang dose |
| `/genz full` | Noticeably slangy default Gen Z voice |
| `/genz max` | Very heavy slang, still coherent |
| `/genz off` | Deactivate |
| `/genz-commit` | Terse commit message |
| `/genz-review` | One-line review findings |
| `/genz-compress <file>` | Compress a Markdown file |
| `/genz-stats` | Lifetime token-savings |

Natural language also works: "turn on genz", "stop genz", "normal mode".

Code, commits, security warnings: Gen Z style drops out automatically.
